# AC8 MouseFlight

为 **ACE COMBAT 8 离线单人模式**提供鼠标指向飞控、独立跟随相机和方向指示。

本分支是**以 Project Wingman（PW）的鼠标操控手感为目标优化的飞控版本**，主要围绕 **F-14D** 进行实机调校。默认参数和附带的 F-14D 预设可作为起点，玩家可以根据机型、飞行习惯和个人偏好自行调整，详见 [参数说明](docs/PW5.md)。

移动鼠标指定一个世界方向，飞机通过俯仰、滚转和偏航输入尝试对准它。目标是提供类似“鼠标指向、飞机追随”的操作方式，而不是改变游戏的飞行模型。

> 仅供离线单人使用。不支持多人模式，也不保证与其他相机、输入或加载器模组兼容。游戏更新后，旧版本模组可能不再适用。

本项目为非官方模组，与游戏开发商、发行商及 War Thunder 无关联。

## 功能

- **鼠标指向飞行**：目标方向保存在世界坐标中，飞机通过三轴输入追随目标。
- **到位制动与改平**：结合机体角速度抑制过冲，在接近目标后逐渐改平。
- **独立跟随相机**：相机平滑朝向目标，保留游戏原有视野角度变化。
- **方向指示**：分别显示鼠标目标与实际机头方向，采用半透明标记。
- **键盘临时超控**：WASDQE 对应的手动轴输入优先，不必关闭鼠标模式。
- **自由观察**：按住 F 环绕观察，飞行目标不变；松开后相机平滑返回目标方向。
- **暂停处理**：游戏暂停时冻结鼠标目标，恢复后将目标重新置于屏幕中心。
- **原生注视与演出让出**：识别长按注视及已验证的演出相机激活状态，暂时让出相机和操控，结束后恢复。
- **可选性能统计**：记录模组工作耗时和帧间隔，辅助排查卡顿。
- **pw.5 飞控改进**：地平线参考与倾斜限制、水平/斜向协调转弯、高 G 按键配合、后方方向保持、陡降输入余量及姿态跳变保护。
- **可配置键位与响应**：通过 INI 调整接管键和功能键；附带可选 F-14D 个人参数预设。

模组修改玩家操作输入和相机视角，不修改气动、推力、武器伤害或存档数据。

## 安装

### 准备

1. 确认游戏版本适用，并完全退出游戏。
2. 本贡献分支使用仓库中的完整 `Payload`、安装脚本及许可文件；上游历史 Releases 仍是对应的原版本。不要只复制 DLL 或单个脚本，也不要将 pw.5 Lua 与上游 DLL 混用。
3. 如已安装旧版，建议先备份自定义 `config.ini`。共存安装器会保留已有配置。
4. 如已有 UE4SS，安装器会检查兼容性；兼容时复用框架，只安装本模组，未知或不兼容的安装不会被覆盖。

### 安装与启动

1. 运行解压目录中的 `Install.cmd`。
2. 在选择窗口中指定游戏根目录，即包含 `Game` 和 `EasyAntiCheat` 的目录。
3. 在 Steam 的游戏“属性 → 通用 → 启动选项”中设置本项目的离线启动参数：

   ```text
   cmd /d /c "set EOS_USE_ANTICHEATCLIENTNULL=1&& %command% -anticheat_settings=AC8MouseAim_Offline.json"
   ```

   若原来有其他启动选项，请先备份，不要未经确认直接拼接。

4. 从 Steam 启动游戏，选择“专家”飞行操作，进入单人任务。
5. 建议使用无边框窗口模式。方向指示使用桌面透明覆盖层，独占全屏下可能不可见。

安装器会校验复制后的关键文件。0.2.30 需要配套的 UE4SS，不要自行替换成其他版本；校验失败时应检查安装，而不是关闭保护。

### 与其他模组共存

共存安装器不再一概拒绝已有 UE4SS：

| 已有环境 | 处理方式 |
| --- | --- |
| 没有框架或冲突加载器 | 安装随包 UE4SS 和本模组 |
| 已验证的兼容 UE4SS、默认 Mods 路径 | 保留框架、加载器、设置和其他模组，仅安装本模组并合并启用列表 |
| 运行库不兼容、多个运行库、自定义路径或重定向 | 写入前停止并说明原因，由用户手动整合 |

兼容性按运行库校验值判断，而非仅比较版本名称；目前只自动支持 `Game/Binaries/Win64/UE4SS` 布局下已验证的运行库。复用模式不会修复、替换或重新启用已有加载器，原有框架必须能够正常工作。

安装前备份保存在游戏根目录的 `AC8MouseAim-Backups`。其他模组的启用状态及顺序保留，本模组条目合并到列表末尾；`mods.json` 的格式化可能变化，但其他字段和值保留。

这解决的是安装层面的共存，**不保证功能层面无冲突**。同时修改玩家输入、相机或相关钩子的模组仍可能互相干扰。

## 操作

| 输入 | 功能 |
| --- | --- |
| 移动鼠标 | 改变飞行目标方向 |
| 按住 F | 自由观察；鼠标只改变观察方向 |
| 松开 F | 相机平滑返回飞行目标方向 |
| W / S | 临时接管俯仰，同时暂停自动滚转 |
| A / D | 临时接管滚转 |
| Q / E | 临时接管偏航 |
| F8 | 开关鼠标辅助模式 |
| F9 | 将目标方向重新对准机头 |
| F10 | 重新读取配置，并重新对准机头 |
| F7 | 开关方向指示层，不关闭飞控 |
| F5 | 开关轻量性能统计，默认关闭 |
| F6 | 开关详细相机状态采集，仅用于专项排查 |

自由观察期间，目标保持原来的**世界方向**，而不是固定在屏幕坐标上；飞机仍会尝试朝该方向飞行。自由观察支持水平环绕，俯仰限制为 ±89°。

上表是默认键位，可在 `[keys]` 中修改并重启游戏生效。模组不会屏蔽游戏原有绑定；飞行轴和高 G 两键应与游戏内绑定一致，功能键应避开冲突。按住默认 Ctrl+Space 时提高自动俯仰响应参考，不改变游戏原生高 G 触发条件或延迟。

### 注视与剧情演出

手动注视需要持续按住约 0.35 秒才触发让出，短按切换锁定目标不会立即退出鼠标模式。该时间是模组的防误触门槛，不代表游戏内部阈值。

注视或已识别的演出期间，模组隐藏指示、冻结鼠标目标并放行原生操控和相机。结束后保留约 0.25 秒缓冲再恢复。当前已验证 `ImpactCamera` 激活路径，但不能保证覆盖所有剧情相机。

## 配置

安装后的配置文件：

```text
Game/Binaries/Win64/UE4SS/Mods/AC8MouseAim/config.ini
```

最常用的设置是鼠标灵敏度：

```ini
[control]
sensitivity=0.10
```

数值越大，移动相同鼠标距离时目标转动越快。修改后可按 F10 重新加载。

配置中部分 `gain`、`damping` 等字段为历史兼容项，并不用于调整当前控制器。请不要把所有字段都当作有效的手感参数。轴符号和输入槽位属于版本适配设置，正常情况下不应修改。

pw.5 新安装默认 `max_bank=85`、`roll_rate_scale=1.25`、`roll_lookahead=0.10`，高 G 偏航增强关闭。可选 `presets/f14d-pw5.ini` 使用用户实测选定的 89 / 1.35 / 0.12，开启偏航增强及诊断。完整字段、键位和应用方式见 [pw.5 配置说明](docs/PW5.md)。

共存升级会保留旧 INI；旧值不会自动改成新默认值，旧 `max_bank=65` 现在会实际限制目标倾斜。缺少的新字段使用内置默认值。选用新默认/个人预设时，先备份原配置，再合并需要的参数并保留自己的灵敏度和键位。

## 性能与问题反馈

### 0.2.30 的优化范围

- 用进程内数字接口替换实时文本管道和相机目标文件。
- 同帧传递姿态与目标，不积压过期帧。
- 原生日志由后台线程写盘，使用有容量限制的队列；繁忙时丢弃诊断信息，而不是等待写盘。
- 输入钩子提前排除非玩家调用，减少重复键盘查询。
- 复用逐帧脚本中的部分读取和转换结果。

以上是上游 0.2.30 的性能改动；pw.5 另行调整飞控，但保留相机与指示层的更新路径。通信延迟减少后，响应可能比旧版更及时。

这些改动针对模组自身的开销，不保证消除游戏资源加载、GPU 瓶颈或其他软件造成的全部卡顿。

### 如何提供有用的卡顿记录

1. 进入容易复现问题的任务，按 F5 开始统计。
2. 正常游玩，经过一次明显卡顿或敌人刷新事件。
3. 再按 F5 结束统计，提供最新的 `MouseAim-xxxxx.log`。

统计约每 10 秒汇总，关闭时补报剩余数据。**不需要同时开启 F6**；F6 是更详细的相机状态采集，会产生额外文件操作。

日志位置：

```text
Game/Binaries/Win64/UE4SS/Mods/AC8MouseAim/Logs/MouseAim-xxxxx.log
Game/Binaries/Win64/UE4SS/UE4SS.log
```

提交 Issue 时建议附上：

- 模组版本、游戏版本。
- CPU、GPU、内存、游戏所在存储设备类型。
- 分辨率、显示模式，以及是否使用其他模组。
- 具体任务和触发情况：持续掉帧、单位刷新卡顿，还是相机/标记视觉顿挫。
- 相关日志；如已有未加载模组时的对照结果，也请说明。

`script_wall` 包含 `native_bridge`，两者不能相加；`frame_gap` 包含游戏其他工作，不等同于模组耗时。统计不测量 GPU 时间，也不能单独证明卡顿原因。

> F8 只停止鼠标辅助，不会卸载模组。关闭 F8 不能作为“完全原版”的性能基线。

## 已知限制与排查

- **游戏更新后失效**：本项目包含版本相关的输入与相机适配。请先禁用模组，等待对应版本支持。
- **看不到方向指示**：检查 F7 状态，并尝试无边框窗口模式。剧情注视或暂停时隐藏标记是预期行为。
- **启动失败、黑屏或崩溃**：退出游戏，先禁用加载器恢复原版；反馈游戏版本和日志，不要混用不同发布包的文件。
- **部分演出未正确让出**：当前状态检测并非覆盖所有演出。请说明任务和触发位置，再按需采集 F6 记录。
- **其他模组冲突**：尤其是输入、相机、覆盖层和共用 UE4SS 的模组，不保证兼容。
- **新版性能待验证**：自动检查不等于实机兼容性或性能验收，欢迎提供可复现反馈。

## 停用、回退与卸载

### 临时停用加载器

退出游戏，在游戏根目录运行 `Disable-Mod-For-Multiplayer.cmd`。脚本会先确认，再停用 `dwmapi.dll` 加载器入口；这会影响共用它的所有模组。脚本**不会修改 Steam 启动选项，也不会处理所有其他类型的加载器**。

若要恢复正常启动，请同时移除本项目的离线启动参数，恢复原来的启动配置。进入多人模式前务必退出游戏并完成停用；F8 不能代替这一步。项目不提供任何联网兼容性或账号安全保证。

### 回退版本

退出游戏后重新安装上一版本的完整发布包。建议保留 0.2.29 安装包，作为性能专项版的回退选择。

### 卸载

退出游戏，在游戏根目录运行 `Uninstall-AC8-Mouse-Aim.ps1`，并手动移除 Steam 中本项目的离线启动参数。

共存安装器附带的卸载脚本只移走本模组及其辅助文件、移除本模组启用项，保留共用加载器、UE4SS、设置和其他模组。移走的文件可从 `AC8MouseAim-Backups` 恢复。

**卸载本模组不等于禁用所有模组。** 其他模组仍可能加载，进入多人模式前需要单独确认。旧版安装包中的卸载脚本没有这一共存保护，请使用新版脚本。

## 开发说明

主要组成：

```text
src/                  原生输入处理、飞控、相机修正、指示层及诊断
Payload/              部署文件；Lua/INI/DLL 位于其中的 UE4SS/Mods/AC8MouseAim
tools/build_native.py  原生检查、Lua 检查、Windows x64 DLL 构建
tools/check_package.py 在模拟目录检查全新安装和共存升级
tests/                控制器回归、实际原生函数隔离检查及 Lua 测试
docs/PW5.md           变更、配置、验证边界
docs/PR_DESCRIPTION.md 供上游审阅的 PR 描述
```

构建需要 Visual Studio 2022 的 MSVC x64 C++ 工具链、Windows SDK，以及 Windows x64 Python 3.13。所需 Lua/UE4SS 头文件已固定在 `src/vendor`，不依赖相邻源码仓库。测试依赖固定的 Lupa 2.8 / Lua 5.4：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --index-url https://pypi.org/simple --require-hashes -r requirements-dev.txt
.\.venv\Scripts\python.exe tools/build_native.py --test-only
.\.venv\Scripts\python.exe tools/build_native.py --update-payload
.\.venv\Scripts\python.exe tools/check_package.py
```

构建器会尝试用 vswhere 查找工具链，也支持 x64 Developer Shell。工具安装在非默认位置时传入 `--vs-dev-cmd '你的 Visual Studio/Common7/Tools/VsDevCmd.bat 完整路径'`。默认先运行测试，再输出 `build/ac8_mouse_aim_010.dll` 和带源码哈希的 `build/BUILD-MANIFEST.json`；仅显式加 `--update-payload` 才同步仓库部署 DLL，`--test-only` 不构建 DLL。文件名保留历史命名，版本为 pw.5、桥接号 35。

安装器检查只写入忽略提交的 `build/fixtures/` 模拟目录，不启动或安装真实游戏。默认/个人预设读取检查与离线模型回归不等于真实飞机性能验收。详细结果见 [验证记录](docs/PW5_VALIDATION.md)。

0.2.30 通过配套 UE4SS 导出的 LuaMadeSimple 接口交换数值，不直接操作 Lua 虚拟机内部结构。原生相机仍在游戏相机更新后进行修正，保留版本、对象和数据时效检查。

请勿通过移除校验来适配未知游戏或加载器版本。修改飞控或相机时，应尽量保留已经稳定的更新时序，并只安排与改动范围相关的验证。
