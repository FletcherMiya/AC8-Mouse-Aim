# pw.11：PW 手感优化飞控

以 **Project Wingman（PW）的鼠标操控手感**为优化目标，参数可根据机型和个人习惯自行调整。

- **改善滚转稳定性**：小幅修正更平稳，大幅转弯保留快速滚转。
- **更充分释放高 G 回旋性能**：允许更充分的俯仰输入；代价是收尾回正可能略有偏移，随后继续修正。
- **优化锁定目标优先级**：短按游戏切换目标键时，优先选择 PW 鼠标目标方向附近、当前武器允许的敌人。保留武器原有锁定范围、种类、耗时和多目标逻辑。

## 配置

修改 `Game/Binaries/Win64/UE4SS/Mods/AC8MouseAim/config.ini` 的 `[control]`，按 F10 重载：

| 参数 | 随包值 | 用途 |
| --- | --- | --- |
| `angle_control` | `1` | 角度误差驱动输入；`0` 切回 pw.5 飞控模式 |
| `rollout_coordination` | `1` | 独立回平与末段补充制动；角度模式下设 `0` 切回 pw.7 飞控 |
| `mouse_target_priority` | `0` | 设 `1` 启用所有武器的鼠标目标方向优先级 |
| `diagnostics` | `1` | 飞控及选敌诊断；无需排查时可设 `0` |

鼠标目标方向是飞控的 `aim`，不是 CTRL/F 自由观察的相机方向。选敌仍由游戏原有短按切换动作触发；不会随鼠标移动自动换目标，也不会给无制导武器增加锁定能力。

随包参数为 `max_bank=89`、`roll_rate_scale=1.35`、`roll_lookahead=0.12`、`high_g_yaw_boost=1`。可选 `presets/f14d-pw11.ini` 使用相同飞控参数，并开启 `mouse_target_priority=1`。这些参数不是所有机型的最优值；完整注释见 INI。旧 `f14d-pw5.ini` 仅保留作历史参考，复制旧预设不能完整回退控制器。

安装器保留已有 INI。升级后需自行补充或合并所需参数，保留个人灵敏度和 `[keys]`；键位修改需重启游戏，飞行轴及高 G 两键应与游戏内绑定一致。DLL/Lua 必须配套使用 **pw.11 / bridge 41**。

## 验证边界

用户已在 Su-57/Su-35 试飞，并反馈 MSL、QAAM、LACM、6AAM、LAGM 简单测试正常。日志中 41 次选敌建议全部被游戏接受，另 2 次无合适候选时正常回退；日志不区分逐次武器型号，不能据此宣称所有武器逐项定量验收通过。

仅用于单机；不修改机体物理性能或游戏原生高 G 触发延迟。构建、回归及安装器检查见 [验证记录](PW11_VALIDATION.md)。
